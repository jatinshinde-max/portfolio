Three production workflows — a mix I've built and customized. Each represents a different output modality: animated talking-head video, image-to-3D mesh conversion, and long-form cinematic video generation.

Workflow 01
Wan InfiniteTalk
Wan 2.1 · Talking Head Video
LoadImage — reference portrait
WanVideoSampler — core generation
CLIPTextEncode — motion prompt
FaceDetector — landmark extraction
InfiniteTalkNode — loop stitching
VideoComposite — frame assembly
VHS_VideoCombine — export
Output
Seamlessly looping portrait video with synchronized facial animation. Photorealistic motion from a single reference image.
Workflow 02
Pixal3D / Trellis2
Trellis2 · Image → 3D Mesh
LoadImage — product/asset reference
ImagePreprocess — background removal
Trellis2ModelLoader — SLAT model
ImageTo3DMesh — reconstruction
Pixal3DRefine — mesh cleanup
GLBExporter — Blender-ready
PreviewMesh — viewport check
Output
GLB mesh with UV-mapped texture. Production-ready for Blender, UE5, or real-time rendering. No manual retopology.

AI Creative Systems

Production tools
I built.

Three custom systems built on top of GPT APIs and prompt engineering. Each automates a specific stage of creative production — from campaign content to cinematic preproduction. Demonstrated below with fictional brand content.

01
AI Creative Production Studio
GPT-Powered · Content Automation
A structured content generation system for social media and advertising campaigns. Takes a brief and outputs platform-ready copy, hashtag strategies, and visual direction notes across multiple formats simultaneously.
Multi-platform batch output (IG / LinkedIn / TikTok / YouTube) Brand voice consistency across formats Campaign concept → post-ready copy in one pass Structured JSON output for downstream automation
Demo brief — fictional brand
Brief: "LUMEX skincare launch — hydration serum, 18–35 female audience, minimal aesthetic." Output: 12 platform posts, 3 campaign angles, visual direction notes for each format. All content below is fictional demo material.
02
AI Story & Cinematic Preproduction Pipeline
GPT-Chained · Preproduction Automation
A chained GPT pipeline that converts a concept or synopsis into a full preproduction package. Generates story treatment, scene-by-scene breakdown, and production shot list in structured format — ready for the director or storyboard artist.
Concept → treatment → scene breakdown in sequence Shot list with camera angle, lens, and movement notes Maintains story consistency across chained calls Outputs structured data for storyboard pipeline input
Demo output — fictional project
Input: "A solitary astronaut discovers a signal in deep space — 90-second atmospheric short." Output: 4-page treatment, 12 scene cards, 38 shots with angle/movement/duration. Fictional project — not a real production.
03
AI Storyboard Production Pipeline
GPT + Image Gen · Batch Storyboarding
A batch storyboard generation system. Takes the shot list output from the Story Pipeline and generates visual panel descriptions for each shot, then sends them to an image generation model in batch. Produces a complete storyboard document ready for production review.
Shot list → visual panel description → generated image Consistent character and environment across panels Batch processing — full storyboard in one run Exports as numbered sequence for editorial use
Demo output — fictional project
From the 38-shot deep-space project above: 38 generated panels, consistent lighting and character design, numbered and exported as a production-ready PDF storyboard. All panels use synthetic models — no real people.
