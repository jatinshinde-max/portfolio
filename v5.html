Three ComfyUI workflows — a mix I've built and customized from the community. The architecture shown below represents the actual node structure of each graph. Rendered outputs will be added when finalized.

Workflow 01
Wan InfiniteTalk
Wan 2.1 · Talking Head Video
LoadImage — reference portrait
WanVideoSampler — core generation
CLIPTextEncode — motion prompt
FaceDetector — landmark extraction
InfiniteTalkNode — loop stitching
VideoComposite — frame assembly
VHS_VideoCombine — export
Output
Seamlessly looping portrait video with synchronized facial animation. Photorealistic motion from a single reference image.
Workflow 02
Pixal3D / Trellis2
Trellis2 · Image → 3D Mesh
LoadImage — product/asset reference
ImagePreprocess — background removal
Trellis2ModelLoader — SLAT model
ImageTo3DMesh — reconstruction
Pixal3DRefine — mesh cleanup
GLBExporter — Blender-ready
PreviewMesh — viewport check
Output
GLB mesh with UV-mapped texture. Production-ready for Blender, UE5, or real-time rendering. No manual retopology.
Workflow 03 — v10
MiniMax H3 Long Video
MiniMax H3 · Cinematic Video Gen
CLIPTextEncode — scene description
LoadImage — optional keyframe
MiniMaxH3Sampler — video synthesis
VideoExtend — sequence chaining
ConsistencyController — v10 custom
FrameInterpolator — smooth motion
VHS_VideoCombine — final export
Output
Extended cinematic sequences up to 60s+. ConsistencyController (v10 addition) maintains visual coherence across chained clips.

AI Story & Cinematic Preproduction Pipeline
GPT-Chained · Preproduction Automation

A chained GPT pipeline that converts a concept into a full preproduction package — story treatment, scene breakdown, and shot list with camera specifications. Output feeds directly into the storyboard pipeline.

Concept → treatment → scene cards → shot list in sequence Shot list includes angle, lens, movement, and duration Maintains narrative consistency across all chained calls Structured data output ready for storyboard pipeline input
